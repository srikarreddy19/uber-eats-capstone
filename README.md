# Uber Eats Operational & Customer Intelligence System

## Overview

An end-to-end Machine Learning capstone that analyzes synthetic Uber Eats operational data to generate business insights through customer segmentation, restaurant segmentation, sentiment analysis, delivery time prediction, and demand forecasting.

## Project Objective

Build an analytical system that helps Uber Eats:

- Segment customers and restaurants
- Understand customer sentiment
- Predict delivery time
- Forecast hourly demand
- Generate actionable business recommendations

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Prophet
- Statsmodels
- Matplotlib
- Git
